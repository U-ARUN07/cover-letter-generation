# CoverCraft AI - Frontend

The modern React + TypeScript + Tailwind CSS web interface for the AI-Powered Cover Letter Generation system (Infosys Springboard Virtual Internship Program 7.0).

## Features
- **Internship Catalog**: Real-time search, filters (Remote / Hybrid / On-site), rich metadata cards (skills, location, stipend, duration).
- **Internship Detail Modal**: Complete breakdown of responsibilities, requirements, and tech stack.
- **Candidate Resume Hub**:
  - Preloaded sample candidates (Arun Kumar, Priya Sharma, Rohan Verma)
  - PDF/DOCX file upload with automatic resume parsing
  - Direct JSON payload editor
- **Qualification Match Gauge**: Visual match score (0-100%), matching skills, identified skill gaps, and AI recommendations.
- **Live Cover Letter Studio**:
  - Real-time generation powered by LangChain
  - Tone selection (Professional, Enthusiastic, Concise)
  - Copy to clipboard, Download as TXT, and Print-ready PDF view.

## Development

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build production bundle
npm run build
```
